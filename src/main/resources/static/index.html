Welcome to Abdul Rehaman Shaik Portal

This Java Spring Boot application is automatically built, packaged, containerized, and deployed using a complete CI/CD pipeline powered by Jenkins and Microsoft Azure.

Technology Stack

Technologies used in this end-to-end DevOps CI/CD lab

⚙️

Jenkins

Jenkins automatically starts the CI/CD pipeline whenever new changes are pushed to GitHub.

📦

JFrog Artifactory

Maven artifacts are stored and retrieved from JFrog Artifactory during the pipeline.

🐳

Docker

The Spring Boot application is packaged into a Docker image using a Java 17 runtime.

☁️

Azure Container Registry

Versioned Docker images are pushed securely to Azure Container Registry.

🚀

Automated Deployment

Jenkins remotely deploys the new image to the Azure Docker VM automatically.

🔐

Managed Identity

Azure Managed Identity provides secure authentication between Jenkins, ACR, and the deployment VM.

CI/CD Pipeline Flow

GitHub → Jenkins → Maven → JFrog → Docker → Azure ACR → Docker VM
